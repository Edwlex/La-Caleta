# La Caleta D'Charly — Web + Panel del Menú

## Cómo usarlo (VS Code)
1. Abre la carpeta `la_caleta` en VS Code.
2. Instala la extensión **Live Server**.
3. Clic derecho en `index.html` → *Open with Live Server* (web pública).
4. Clic derecho en `admin.html` → *Open with Live Server* (panel para los señores).

## Para publicar (gratis)
- Sube toda la carpeta a **Netlify** o **Vercel** (arrastrar y soltar).
- Después de editar en el panel, usa *Descargar data.js* y reemplaza el archivo en la carpeta publicada.
